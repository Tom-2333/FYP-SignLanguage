1) 摘要
==================================================
本報告記錄 ChatBox 從 NVIDIA API 流程切換到 Grok-Api 流程後所遇到的整合問題，包含前端啟動混淆、後端代理/設定問題，以及 Grok-Api 上游解析器失效。

主要結論：
- 本機服務可啟動（Apache、MySQL、React、Grok-Api）。
- 前後端路由問題已修正。
- 目前主要阻塞點為 Grok-Api 解析器與最新 grok.com bundle 不相容（上游問題），現已可回傳清楚錯誤訊息。

==================================================
2) 已回報症狀
==================================================
A. 前端訊息：
   "Generation failed: Grok API Error (504): Error occurred while trying to proxy: localhost:3000/ask"

B. 前端訊息：
   "Grok service is unreachable. Please start Grok-Api server on http://localhost:6969 and retry."

C. 瀏覽器錯誤頁：
   localhost 出現 ERR_CONNECTION_REFUSED

D. 後端訊息：
   "Generation failed: Grok API Error (500): Error: cannot access local variable 'script_content1' where it is not associated with a value"

==================================================
3) 已確認根因
==================================================
根因 1：前端路由目標錯誤/不明確
- 專案同時存在多種代理行為與端點假設。
- 請求可能誤送到 /ask，而非 /api/grok/ask。

根因 2：React 開發伺服器未啟動
- Apache/MySQL 有啟動，不代表 React 前端也有啟動。
- 當 localhost:3000 未監聽時，就會出現 ERR_CONNECTION_REFUSED。

根因 3：Grok-Api 請求契約不一致
- Grok-Api 預期 proxy 欄位為字串；送入 null 會造成驗證錯誤。

根因 4：Grok-Api 後端在本地版本要求嚴格 proxy
- api_server.py 原本要求 proxy + message 必填；proxy 為空會回 400。

根因 5：Grok-Api 解析器與最新 grok.com 腳本版型不相容
- 內部 parser 找不到預期標記（anonPrivateKey）。
- 此為 Grok-Api 實作層面的上游相容性問題。

4) 已套用修改
==================================================
專案：my-app

4.1 ChatBox API 遷移與強化
- 檔案：my-app/src/pages/chatBox.jsx
- 修改內容：
  - 將請求流程由 NVIDIA completion payload 改為 Grok-Api /ask payload：
    { proxy, message, model, extra_data }
  - 新增 grokExtraData 狀態以延續多輪對話。
  - 正規化/保護 API URL：
    - env 為空或為 /ask 時，強制使用 /api/grok/ask
  - 新增更清楚的網路/代理失敗提示。
  - 修正 payload 型別：
    - proxy 一律送字串（預設：""）
    - extra_data 僅在為物件時才送出
  - 新增對 API 回傳 { error } 的檢查，拋出可讀錯誤。

4.2 新增 Grok 開發代理路由
- 檔案：my-app/src/setupProxy.js
- 新增路由：
  - /api/grok -> http://localhost:6969
  - pathRewrite: '^/api/grok' => ''

4.3 移除過於寬鬆的 package-level proxy，降低誤路由
- 檔案：my-app/package.json
- 移除 "proxy": "https://integrate.api.nvidia.com"

4.4 更新環境變數
- 檔案：my-app/.env
- 新增：
  - REACT_APP_GROK_API_URL=/api/grok/ask
  - REACT_APP_GROK_MODEL=grok-3-fast
  - REACT_APP_GROK_PROXY=


專案：Grok-Api（本機 clone）

4.5 API server 支援可選 proxy
- 檔案：Grok-Api/api_server.py
- 修改內容：
  - proxy 由必填 str 改為 Optional[str]
  - message 仍為必填
  - 只有在提供 proxy 時才進行格式化

4.6 較安全的本機執行預設
- 檔案：Grok-Api/api_server.py
- workers 由 50 改為 1，提升本機穩定與除錯可讀性

4.7 Anti-bot 遞迴保護
- 檔案：Grok-Api/core/grok.py
- 遇到 anti-bot 拒絕時，改回傳可讀錯誤，不再遞迴重試。

4.8 Parser 防呆與清楚錯誤診斷
- 檔案：Grok-Api/core/reverse/parser.py
- 在迴圈前初始化 script_content1/script_content2/action_script。
- 找不到必要腳本標記時，明確拋出 RuntimeError。
- 將 unbound local variable 類錯誤改為可行動的 parser 錯誤訊息。
