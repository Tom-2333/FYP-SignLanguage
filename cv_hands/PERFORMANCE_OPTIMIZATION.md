# 性能優化報告

## 問題診斷
原始 FPS: **7-8 FPS**  
目標 FPS: **15+ FPS**

## 發現的主要瓶頸

### 1. **過多的 MediaPipe 模型同時運行** ⚠️
- 原本同時運行 3 個模型：
  - `Hands` (手部檢測)
  - `FaceMesh` (臉部網格 - 478 個地標點)
  - `Pose` (姿勢檢測 - 33 個地標點)
- **影響**: 每幀需要處理 3 個深度學習模型，極度消耗 CPU/GPU 資源

### 2. **複雜的特徵提取計算** ⚠️
- 每幀計算多達 40+ 個額外特徵：
  - 10 個臉部特徵 (頭部姿勢、眼睛注視、嘴巴開合)
  - 8 個姿勢特徵 (肩膀位置、軀幹方向)
  - 22 個相對位置特徵
- **影響**: 複雜的數學運算和矩陣操作

### 3. **繁重的繪圖操作** ⚠️
- 繪製所有 478 個臉部地標點
- 繪製姿勢骨架和連接線
- 使用 PIL 進行中文文字渲染（需要 BGR↔RGB 轉換）
- **影響**: 圖像處理和色彩空間轉換耗時

### 4. **使用 Keras 模型而非 TFLite** ⚠️
- Keras `.predict()` 方法較慢
- **影響**: 推理時間增加 2-3 倍

### 5. **過高的解析度** ⚠️
- 原始設定：960x540
- **影響**: 像素處理量大

## 已實施的優化方案

### ✅ 優化 1: 移除不必要的模型
```python
# 移除了 face_mesh 和 pose 模型
# 手勢識別只需要手部檢測即可
face_mesh = None
pose = None
```
**預期提升**: ~3-4 FPS

### ✅ 優化 2: 簡化特徵提取
```python
# 改用 legacy mode，只使用手部 42 個特徵點
# 移除臉部、姿勢和相對位置的 40+ 個額外特徵
use_legacy_mode=True
```
**預期提升**: ~2-3 FPS

### ✅ 優化 3: 減少繪圖操作
```python
# 註釋掉臉部和姿勢地標的繪製
# debug_image = draw_face_landmarks(debug_image, face_landmarks)  # 已移除
# debug_image = draw_pose_landmarks(debug_image, pose_landmarks)  # 已移除
```
**預期提升**: ~1-2 FPS

### ✅ 優化 4: 優化文字渲染
```python
# ASCII 文字使用快速的 cv.putText()
# 只對中文字符使用較慢的 PIL
if text.isascii():
    cv.putText(image, text, position, ...)  # 快速路徑
```
**預期提升**: ~1 FPS

### ✅ 優化 5: 使用 TFLite 優先
```python
# 優先使用 TFLite 而非 Keras
# TFLite 推理速度快 2-3 倍
num_threads=2  # 提升到 2 個線程
```
**預期提升**: ~2-3 FPS

### ✅ 優化 6: 降低解析度
```python
# 640x480 (降低 ~30% 像素)
default=640  # 原 960
default=480  # 原 540
```
**預期提升**: ~2-3 FPS

### ✅ 優化 7: 使用輕量級手部模型
```python
model_complexity=0  # 0=輕量級, 1=完整版
min_detection_confidence=0.5  # 降低閾值加快檢測
```
**預期提升**: ~1-2 FPS

## 如何測試

1. 運行優化後的程序：
```bash
python app.py
```

2. 檢查左上角顯示的 FPS 數值

3. 如果需要更高性能，可以：
   - 進一步降低解析度：`python app.py --width 480 --height 360`
   - 只檢測單手：將 `max_num_hands=2` 改為 `max_num_hands=1`

## 功能影響評估

### ✅ 保留的功能
- 手勢識別（單次和序列）
- 手部地標繪製
- FPS 顯示
- 所有原始模式 (k, s, n, o)
- 資料記錄功能

### ❌ 移除的功能
- 臉部地標檢測和顯示
- 姿勢骨架檢測和顯示
- 基於臉部/身體的相對位置特徵

### 💡 注意事項
如果您的模型是用擴展特徵（80 個特徵）訓練的，可能需要：
1. 使用 42 個特徵的舊模型
2. 或重新訓練模型（使用簡化的 42 個特徵）

## 還原方法

如果需要還原原始功能，修改以下設置：
```python
# 在 app.py 中
use_legacy_mode=False  # 改回 False 啟用完整特徵
```

並取消註釋：
```python
# 重新啟用 face_mesh 和 pose 初始化
# 重新啟用繪圖函數
```
