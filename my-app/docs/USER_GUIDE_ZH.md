# 手語學習平台使用者指南（中文）

## 1. 文件目的
本文件說明如何使用手語學習平台的主要功能，包含：
- 註冊與登入
- 詞彙學習與手勢辨識
- 手語句子生成與聊天紀錄
- 支援資源查詢
- 設定（語言、主題、字型大小、無障礙）

本指南依照目前前端頁面與你提供的介面截圖整理，可直接作為展示或交付文件。

## 2. 系統需求與啟動前準備
### 2.1 基本需求
- 可使用現代瀏覽器（建議 Chrome）
- 需允許相機權限（用於手勢辨識）
- 需可連線資料庫 API 與手勢辨識服務

### 2.2 後端服務（手勢辨識）
若詞彙頁顯示「連接中」或離線提示，請啟動手勢服務：
1. 開啟終端機，切換到 cv_hands 目錄。
2. 使用 Python 3.10 執行：

```bash
py -3.10 app_simple.py
```

3. 預設服務位址：
- Health: http://127.0.0.1:5001/api/v1/health
- WebSocket: ws://127.0.0.1:5001/api/v1/ws/gesture

## 3. 導覽與頁面結構
平台主要頁面：
- 詞彙頁
- 聊天室
- 支援
- 設定
- 登出

左下角有浮動選單按鈕（漢堡圖示），點開可切換上述頁面。

## 4. 註冊與登入
### 4.1 建立帳戶
1. 進入註冊頁。
2. 輸入：全名、電子郵件、密碼。
3. 按「建立帳戶」。

### 4.2 登入
1. 進入登入頁。
2. 輸入電子郵件與密碼。
3. 按「登入」。
4. 成功後會進入詞彙頁。

### 4.3 驗證規則
- 電郵格式需有效（至少包含 @）
- 密碼至少 6 個字元
- 必填欄位不可空白

## 5. 詞彙學習頁（核心功能）
### 5.1 畫面重點
- 辨識率進度條（上方）
- 分類區（左側）
- 單字清單與分頁（中間）
- 手語示範區（示範影像）
- 你的手語（相機即時畫面）
- 診斷區（WebSocket / Health 狀態）

### 5.2 基本操作
1. 在分類區選擇主題（可選「所有詞彙」）。
2. 點選目標詞彙後，切換到示範模式。
3. 觀看該詞彙示範影像。
4. 開啟相機並做手勢。
5. 系統比對「序列辨識文字」與所選詞彙，成功後顯示完成狀態並記錄進度。

### 5.3 搜尋與分頁
- 可在搜尋欄輸入中文或英文關鍵字。
- 每頁顯示固定數量詞彙，可用下方分頁按鈕切頁。

### 5.4 診斷資訊（除錯用）
按「Show Diagnostics / Hide Diagnostics」可查看：
- WebSocket 連線狀態
- Health API 狀態與延遲
- 最後訊息時間
- 錯誤訊息（若有）

## 6. 聊天室與手語句子生成
### 6.1 畫面重點
- 左側：歷史對話清單、搜尋歷史、新對話
- 右側：句子生成區、聊天訊息區、手語圖示區、輸入列

### 6.2 句子生成功能
1. 按「生成手語句子」。
2. 系統會產生正常原句與手語表達。
3. 若已有內容，按鈕會變成「繼續生成手語句子」。

### 6.3 顯示手語圖示
- 按「顯示手語圖示」可展開每個詞彙對應圖片。
- 按「隱藏手語圖示」可收合圖片列。

### 6.4 攝影機輸入模式
- 右下角可切換相機模式與鍵盤輸入模式。
- 相機開啟時，輸入框會改為辨識顯示模式。

### 6.5 歷史紀錄
- 可建立「新對話」。
- 可點選左側歷史對話回看內容。
- 可用搜尋框篩選歷史紀錄。

## 7. 支援資源頁
此頁整理香港聽障與手語相關資源，包含：
- 主要非政府組織
- 政府服務資訊
- 緊急支援（如 992 短訊）

每張卡片提供網址、電話或簡介，可直接點連結查詢。

## 8. 設定頁
### 8.1 可設定內容
- 帳戶資訊（暱稱、電郵）
- 外觀模式（淺色 / 深色）
- 字型大小（aa / Aa / AA）
- 無障礙（色盲友善模式 RG-CVD）
- 介面語言（繁體中文 / English）

### 8.2 儲存設定
- 修改後會顯示「儲存設定」按鈕。
- 按下後會寫入本機設定，重新整理後仍會保留。

### 8.3 登出
- 可在設定頁或浮動選單按「登出」。

## 9. 常見問題排除
### 9.1 相機畫面全黑或無法辨識
- 先確認瀏覽器已允許相機權限。
- 重新整理頁面後再試。

### 9.2 詞彙頁一直顯示連接中
- 確認手勢服務已啟動（Python 3.10）。
- 檢查 Health API 是否可連線。

### 9.3 沒有顯示手語圖示
- 先確認已按「顯示手語圖示」。
- 部分詞彙可能暫無對應圖檔。

### 9.4 聊天句子生成失敗
- 可能是模型 API 暫時不可用或超出速率限制。
- 請稍後重試。

## 10. 建議操作流程（給新使用者）
1. 先在設定調整語言與字型大小。
2. 到詞彙頁選一個簡單詞彙練習。
3. 確認相機辨識正常後，再到聊天頁生成句子。
4. 需要外部協助時，使用支援頁的官方資源連結。
